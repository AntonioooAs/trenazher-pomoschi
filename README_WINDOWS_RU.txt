WINDOWS-ВЕРСИЯ

1. Загрузите проект в GitHub.
2. Откройте Actions.
3. Выберите Build Windows Desktop App.
4. Нажмите Run workflow.
5. После завершения откройте выполненный workflow и скачайте artifact trenazher-pervoy-pomoschi-windows.
6. Внутри будут: установщик *-Setup-*.exe и portable *-Portable-*.exe.

Установщик ставит обычную программу Windows. Portable-версия запускается без установки.
